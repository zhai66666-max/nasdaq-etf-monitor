# 纳斯达克100 ETF 溢价率 + 历史回撤监控系统

每天北京时间 **07:21** 自动运行，回答两个问题：

> **纳指现在处于历史什么级别的回撤？**
> **如果加仓，国内哪个纳指ETF现在买得最便宜？**

核心逻辑：**历史回撤 × ETF溢价率** —— 在纳指出现历史级别回撤时，自动寻找国内场内价格最合理的纳指100 ETF。

## 功能

- 📉 纳斯达克100 **完整历史回撤**计算（1996年至今，非52周回撤）
- 📊 历史回撤百分位、历史最大回撤（-82.9%，2000互联网泡沫）
- 🔴 回撤事件自动识别（-10%/-15%/-20%/-30%/-40% 阈值）
- 🏆 12只国内纳指ETF溢价率实时计算与排序（溢价率→流动性→价差）
- 🎯 历史回撤×溢价率综合矩阵 → 加仓条件判断
- 📧 精美HTML邮件，每天自动发送
- 💾 DuckDB长期数据库，积累历史数据

## 核心指标

### 1. 纳斯达克100历史回撤（第一核心）

```
当前历史回撤 = 当前收盘价 / 历史最高收盘价 - 1
```

使用1996年至今的**完整历史**，覆盖互联网泡沫、2008金融危机、2020疫情、2022加息熊市。

### 2. 国内纳指ETF溢价率（第二核心）

```
溢价率 = (场内价格 / 基准 - 1) × 100%
```

免费数据源无可靠实时IOPV接口，溢价率基于**东财最新净值(T-1)**并在邮件中明确标注，不伪装成实时IOPV。

## 回撤等级

| 回撤区间 | 等级 |
|---|---|
| 0 ~ -5% | 🟢 正常波动 |
| -5% ~ -10% | 🟢 普通回撤 |
| -10% ~ -15% | 🟡 中等回撤 |
| -15% ~ -20% | 🟠 较大回撤 |
| -20% ~ -30% | 🔴 重大回撤 |
| -30% ~ -40% | 🔴 极端回撤 |
| < -40% | 🔥 历史级危机 |

等级可在 `config/strategy.yaml` 自定义。

## 溢价等级

| 溢价率 | 状态 |
|---|---|
| ≤0% | 🟢 极佳 |
| 0~1% | 🟢 很好 |
| 1~2% | 🟢 **可买** |
| 2~3% | 🟡 谨慎 |
| 3~5% | 🟠 不优先 |
| 5~8% | 🔴 高溢价 |
| >8% | 🔴 极高溢价 |

默认规则：**溢价率 ≤2% → 场内价格可以接受**（与历史回撤结合判断）。

## 综合判断矩阵

| 纳指历史回撤 | ETF溢价 | 系统状态 |
|---|---|---|
| < -5% | ≤2% | 🟢 正常定投 |
| -5%~-10% | ≤2% | 🟢 可正常加仓 |
| -10%~-15% | ≤2% | 🟢 加仓区 |
| -15%~-20% | ≤2% | 🔥 强加仓区 |
| -20%~-30% | ≤2% | 🔥🔥 极端加仓区 |
| <-30% | ≤2% | 🔥🔥🔥 历史级回撤 |

矩阵可在 `config/strategy.yaml` 自定义。

## 数据源

| 数据 | 主数据源 | 备用 |
|---|---|---|
| 纳斯达克100历史 | NASDAQ官方API（1996至今，分页） | yfinance → 缓存CSV |
| ETF实时行情 | 腾讯行情 | 东方财富 |
| ETF净值基准 | 东方财富T-1净值 | — |

单只ETF失败不影响整体运行，邮件中明确显示数据状态。

## 本地运行

```bash
pip install -r requirements.txt
python main.py --no-send   # 只生成报告不发送
python main.py             # 完整运行含邮件
```

## GitHub Actions

每天北京时间 07:21（UTC 23:21）自动运行，同时支持手动触发。

Secrets 配置：

| Secret | 说明 |
|---|---|
| `EMAIL_HOST` | smtp.qq.com |
| `EMAIL_PORT` | 465 |
| `EMAIL_USERNAME` | 发送邮箱 |
| `EMAIL_PASSWORD` | QQ邮箱授权码 |
| `EMAIL_TO` | 接收邮箱（逗号分隔多个） |

## 数据库

`data/market.duckdb`（DuckDB）：

- `nasdaq_daily` — 日线+峰值+回撤序列
- `etf_daily` — 每日ETF快照（价格/溢价/净值）
- `drawdown_events` — 历史回撤事件
